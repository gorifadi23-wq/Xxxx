# قارئ ومحرك بحث Excel

تطبيق موبايل بسيط وسريع للبحث في ملفات Excel باستخدام Flet و Python.

## المميزات

- 📱 واجهة عربية سهلة الاستخدام (RTL)
- 🔍 بحث سريع في جميع أعمدة الملف
- 📊 دعم ملفات Excel (.xlsx و .xls)
- 🎯 عرض نتائج البحث في بطاقات منظمة
- ⚡ أداء عالي مع البيانات الكبيرة

## المتطلبات

- Python 3.11+
- Java 17 (لبناء APK)
- Flutter 3.22+

## الحزم المطلوبة

```bash
pip install flet pandas openpyxl
```

## الاستخدام

### تشغيل على الجهاز المحلي

```bash
flet run main.py
```

### بناء APK لنظام Android

```bash
flet build apk
```

سيتم إنشاء ملف APK في المجلد `build/apk/`

## كيفية الاستخدام

1. اختر ملف Excel من هاتفك باستخدام زر "اختيار ملف Excel"
2. اكتب الكلمة أو الرقم المراد البحث عنه في حقل البحث
3. ستظهر النتائج تلقائياً في قائمة النتائج
4. يمكن التمرير للأسفل لرؤية جميع النتائج

## الأخطاء الشائعة والحلول

### خطأ: "لم يتمكن من الوصول إلى مسار الملف"
- تأكد من أن الملف موجود وقابل للقراءة

### خطأ: "حدث خطأ أثناء قراءة الملف"
- تحقق من أن الملف بصيغة Excel صحيحة
- جرب إعادة تسمية الملف وحذف المسافات

### البحث بطيء مع الملفات الكبيرة
- هذا طبيعي مع الملفات التي تحتوي على ملايين الصفوف
- تأكد من أن جهازك يحتوي على ذاكرة كافية
